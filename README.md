# É MOOMENTS 100 — DAZN AWARDS 2026 ファン投票プロトタイプ

2026年、スポーツが心を震わせた100のモーメントを、シームレスに動くモザイクUIで眺めて・遊んで・投票できるプロトタイプです。
「投票してください」ではなく、**眺めているだけでワクワクし、ザッピング感覚の行動が自然と投票につながる**体験を検証します。

## 体験の流れ

1. **モザイク** — 100本のハイライトが隙間なく敷き詰められ、常にゆらぎながら動く。タイルの大きさは**投票数に応じてリアルタイムに変化**し、カーソルを合わせたタイルはシームレスに拡大する。投票数上位のタイルはミュート自動再生。
2. **詳細ビュー** — タイルを選ぶと動画再生・解説・感情タグ・投票数・寄せられたコメントを表示。ひとことコメントを添えて投票できる。
3. **投票後のプレゼント映像** — 黒背景に自分のコメントがタイプライター演出で流れ、コメントから推定した感情（歓喜/涙/鳥肌/緊張/一体感/別れ/逆転/気迫）に**感情的に近しいハイライトがテンポよくカット**され、最後に自分が投票したモーメント → DAZNロゴで締まる。

## 技術構成

- **Next.js 14 (App Router, TypeScript)** — フロント + API を1コンテナで提供
- **データ**: `data/moments.json` — 実在のYouTube動画100本に、タイトル・競技・解説・**感情パラメータ（emotions: 主感情が先頭）** を後付け定義
- **レイアウト**: 重み付きBSP（`lib/layout.ts`）。固定順のまま重み比で矩形を再帰分割するため、投票・ホバー・ゆらぎによるサイズ変化がシームレスに補間される
- **感情マッチング**: `lib/emotion.ts` の辞書ベース推定（プロトタイプ用。本番はClaude API等に差し替え想定）
- **投票ストア**: インメモリ（`lib/store.ts`）。シード値から初期投票数を分布生成。**Cloud Runはステートレスのため再起動で戻ります** — 本番は Firestore 等へ差し替え

## 開発

```bash
npm install
npm run dev   # http://localhost:3000
```

## Cloud Run へのデプロイ

```bash
gcloud run deploy e-mooments \
  --source . \
  --region asia-northeast1 \
  --allow-unauthenticated
```

（`Dockerfile` 同梱。`--source` 指定で Cloud Build がそのままビルドします）

## プロトタイプ上の注意

- 映像素材は現時点で **YouTubeの実在動画（サムネイル + 埋め込みプレイヤー）** で代用。動画IDはWeb検索結果から収集したもので、削除・地域制限・埋め込み不可のものが混ざる可能性があります。本番ではmp4素材（自社CDN配信）に差し替える前提の作りです（`lib/youtube.ts` を差し替えるだけで済むよう分離済み）
- サムネイル取得不可のタイルはグラデーション+タイトルのフォールバック表示になります
- 投票後の「感情的に近いハイライト」はプレゼント映像内では権利面を考慮しサムネイルのシネマティック演出（Ken Burns + カット割り）で表現しています

## データの拡張

`data/moments.json` の1件:

```json
{
  "id": "M001",
  "index": 1,
  "youtubeId": "b1zeCbD4aC0",
  "title": "平野歩夢、トリプルコークで悲願の金",
  "sport": "オリンピック",
  "event": "北京2022オリンピック スノーボード男子ハーフパイプ 決勝",
  "year": 2022,
  "description": "…",
  "emotions": ["気迫", "逆転", "歓喜"]
}
```

`emotions` の語彙は `lib/types.ts` の `EMOTIONS`（8種）で固定しています。
